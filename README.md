# LifeSystem

AI-Powered Personal Progression & Guidance System.

## Vision

LifeSystem is designed to help users understand their current
situation, identify areas that need attention, take useful actions,
and track long-term personal progress.

## Core Areas

- Physical
- Educational
- Mental Wellness
- Emotional Wellbeing
- Career / Life Goals

## Core Principle

The system should not simply ask:

"What tasks should I complete?"

Instead:

"Given my current situation, goals, progress and available resources,
what is the most useful next step?"
